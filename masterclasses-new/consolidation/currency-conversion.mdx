Francis converts each entity's actuals into a single reporting currency before they roll up to the consolidated template. This guide walks you through enabling that per entity.

## Before you start

Connect a currency data source in **Settings > Integrations**. See [Currency](/integrations-new/other/currency) for setup detail.

## Enable conversion per entity

Open **Settings > Integrations** and select the accounting integration for the entity. Confirm the functional currency Francis has detected, select your currency data source, and set the target reporting currency. Repeat for each entity in your group.
