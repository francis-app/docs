A consolidated model in Francis gives you actuals across all entities in one place, with the option to forecast each entity separately. This guide takes you from connected data sources to a working consolidated model.

## Before you start

Connect an accounting integration for each entity. Create your model from the [group template](/features-new/using-francis/getting-started) — it gives you a reliable, editable framework to build from. Then go to Mappings in the top-left and drag GL accounts onto the relevant line items.

<Note>
  If you haven't set up your integrations yet, see [Accounting integrations](/integrations/accounting/overview) first.
</Note>

## Breakdown by entity

Breaking down your consolidated sheet creates a consolidation template with one instance per entity. This is what enables per-entity forecasting.

<Warning>
  Applying a breakdown deletes any pre-existing forecasts and manual entries on the sheet. Do this before you start forecasting, not after.
</Warning>

Hover over the sheet containing your consolidated actuals, open the action menu (...), then choose **Breakdown by...**. In the modal, select your entities and confirm.

Once applied, the sheet becomes a consolidation template. Structure — rows, groups, formulas — is defined top-down in the template and syncs automatically to all instances. Actuals and forecasts are defined bottom-up in the instances and roll up to the template. You can't edit cell values in the template directly; edit the instances instead.
