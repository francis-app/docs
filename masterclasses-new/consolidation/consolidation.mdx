A consolidated model in Francis gives you actuals across all entities in one place, with the option to forecast each entity separately. This guide takes you from connected data sources to a working consolidated model.

## Before you start

Connect an [accounting integration](/integrations-new/accounting/overview) for each entity. If entities operate in different base currencies, set up [currency conversion](/integrations-new/other/currency) at this stage. Create your model from a [template](/features-new/using-francis/getting-started) or from scratch. Templates give you a reliable, editable framework; starting from scratch is an option if you're replicating an existing model. A template is the faster path for most. Then go to [Mappings](/features-new/using-francis/data-mappings) and drag GL accounts onto the relevant line items.

## Breakdown by entity

Breaking down your consolidated sheet creates a consolidation template with one sub-sheet per entity. This is what enables per-entity forecasting.

Hover over the sheet containing your consolidated actuals, open the action menu (...), then choose **Breakdown by...**. In the modal, select your entities and confirm.

<Warning>
  Applying a breakdown deletes any pre-existing forecasts and manual entries on the sheet. Do this before you start forecasting, not after.
</Warning>

Once applied, the sheet becomes a consolidation template. Structure (rows, groups, calculations) is defined top-down in the template and syncs automatically to all sub-sheets. Actuals and forecasts are defined bottom-up in the sub-sheets and roll up to the template. You can't edit cell values in the template directly; edit the sub-sheets instead.

## Sub-consolidation

If you need a view that covers only a subset of entities (a regional P&L or a specific holding structure), create a sub-consolidation alongside the main consolidation. Add a new sheet and use calculations to reference the specific sub-sheets you want to include. The consolidation template handles the full group view; the sub-consolidation sits next to it as a separate sheet without affecting the underlying structure.
