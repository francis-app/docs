Status indicators let you tag rows in your model to track progress and flag items that need input. The meanings are suggestions. Adapt them to fit how your team works.

- ⚪ **No status**
- 🔴 **To-do**
- 🟡 **In progress**
- 🟢 **Done**

## Set a status

Open the action menu on any row and select the status you want to assign. All rows default to **No status**.

## Status propagation

Statuses propagate up to groups automatically. If any row within a group has a status set, the most critical status across those rows is shown at the group level.

**To-do** is treated as the most critical status. If a group contains a mix of **To-do**, **In progress**, and **Done** rows, the group displays **To-do**. This makes it easy to spot parts of your model that still need attention, even when rows are collapsed inside nested groups.
