Breakdowns split your model so you can plan and review data per sub-unit. You can apply a breakdown to an entire sheet or to a single row.

## Sheet breakdown vs. line item breakdown

A breakdown applies at one of two levels.

**Sheet breakdown** splits the entire sheet. The sheet becomes a template deployed across sub-units. Use this when you want to apply a template across entities, departments, or similar. An example is creating a P&L template per entity or department.

**Line item breakdown** splits a single row. Use this when only one line needs to be split. Examples include splitting a revenue line by product or splitting CAPEX by project.

## Sheet breakdown

Sheet breakdowns come in two types: entity and dimension. Entity comes first and is always the foundation. Dimension breakdowns, by department, channel, or project, sit under entity sub-sheets.

### How it works

When you apply a sheet breakdown, the sheet becomes a template. Structure flows top-down: rows, groups, and calculations you define on the template sync automatically to all sub-sheets. You build the model once and every sub-sheet inherits it.

Data flows bottom-up: actuals and forecasts live on the sub-sheets and roll up to the template automatically. You cannot edit row values directly on the template.

Formulas on sub-sheets can reference other sheets in your model using standard Francis formula syntax. References resolve correctly per sub-sheet.

<Warning>
  Applying a breakdown removes any forecasts and manual entries on the sheet. Apply breakdowns before you start forecasting, not after.
</Warning>

### Apply an entity breakdown

Hover over the consolidated sheet, open the action menu (...), choose **Breakdown**, and select **Entity**. Francis creates one sub-sheet for each of the first 20 entities. If you have more than 20, the remainder roll up into an **Unallocated** sub-sheet. Use **Adjust breakdown** to add individual sub-sheets for entities 21, 22, and so on.

### Apply a dimension breakdown

Hover over the entity sub-sheet you want to break down, open the action menu (...), choose **Breakdown**, and select your dimension. Francis creates one sub-sheet for each of the first 20 dimension values. If you have more than 20, the remainder roll up into an **Unallocated** sub-sheet. Use **Adjust breakdown** to add individual sub-sheets for additional values.

Entity breakdown must be in place before you apply a dimension breakdown on a multi-entity model. Applying a dimension breakdown before entity breakdown only affects the first entity and won't give you unified dimensions across entities.

### Additional settings

Once a breakdown is applied, three additional options appear in the action menu (...) on the template sheet.

**Add sheet** creates a synthetic sub-sheet that is not tied to an entity or dimension value. Name it anything. Use this for consolidation adjustments that should only affect the consolidated view: eliminations, intercompany corrections, or top-level adjustments that must not flow back to individual entity or department P&Ls.

**Add roll-up** creates a consolidated view of a subset of sub-sheets. Open the action menu on the template, choose **Add roll-up**, and drag the relevant sub-sheets into it. The roll-up shows a combined view of those sub-sheets without affecting the individual sub-sheets themselves. Use this when you want a regional or functional consolidation sitting below the full consolidated view.

**Adjust breakdown** lets you rename breakdown values and group multiple values together. Use this to combine departments or dimension values that you want to report as one (for example, grouping Sales and Marketing into a single sub-sheet). Values you don't need can be grouped into an unallocated bucket to keep the model clean without losing the underlying data.

## Line item breakdown

A line item breakdown splits a single row rather than the whole sheet. Hover over the row, open the action menu (...), choose **Breakdown**, and select the dimension to split by. Francis creates one sub-row per dimension value directly below the parent row. The parent row becomes a read-only roll-up of all sub-rows. The same 20-value limit applies: if the dimension has more than 20 values, the remainder roll up into an **Unallocated** sub-row. Use **Adjust breakdown** to add sub-rows for additional values.

<Warning>
  Removing a breakdown removes forecasts entered on the sub-sheets.
</Warning>
