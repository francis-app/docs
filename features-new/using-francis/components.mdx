Components are the five building blocks of every Francis model: rows, calculations, groups, sections, and sheets. Knowing which to use, and where, is the main lever on how quickly you can build and how easy the model is to maintain.

## Rows

Rows are your primary forecast lines. Write formulas in each period cell to build your forecast, and map rows to your general ledger accounts via [data mappings](/features-new/using-francis/data-mappings) to pull in actuals automatically.

<Note>
  A row mapped to an external data source shows a green connection indicator. Unmapped rows show gray.
</Note>

## Calculations

Calculations are time-consistent: whatever formula or value you enter applies identically across every period in the model. Use them for anything derived from other rows. If a value comes from other rows, it belongs in a calculation, not a row.

Common use cases:
- Subtotals and margins
- KPIs such as headcount ratios, CAC, and LTV
- Cash flow statement line items built using the indirect method

## Groups

Groups are containers for rows and calculations. By default, a group sums everything inside it.

Common uses:
- Revenue streams
- Direct costs
- OPEX categories
- Asset, liability, and equity buckets

<Tip>
  Reference groups in formulas rather than individual rows. When you add a new row to a group, any formula pointing to the group picks it up automatically. No manual updates needed as the model grows.
</Tip>

## Sections

Sections define the layout of your model and don't affect numbers or calculations. They contain groups, rows, and calculations.

Common sections:
- Profit and loss
- Balance sheet
- Cash flow
- Revenue breakdown
- Assumptions and drivers
- Headcount

<Note>
  PDF reports are generated by selecting which sections to include. Settle on your reporting format before structuring the model. Reorganizing sections later is much harder.
</Note>

## Sheets

Sheets split a model into separate tabs. They behave like tabs in Excel or Google Sheets, and you can reference components across sheets using Francis [formula](/features-new/using-francis/formulas) syntax. Drag and drop components between sheets to reorganize without breaking references.
