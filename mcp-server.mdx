The Francis MCP server lets AI clients such as Claude, ChatGPT, and Cursor read your Francis data. Ask questions about your model in the AI tool you already use, without exporting to Excel or copying numbers into a chat.

MCP (Model Context Protocol) is an open standard for connecting AI apps to external data. Any client that supports MCP can connect to Francis once a workspace Owner has authorized it.

## Availability

The MCP server is available on every Francis plan at no extra cost.

The MCP server isn't supported for [Limited Viewers](/features/admin/members-and-roles#limited-viewer). Every other role (Owner, Admin, Editor, and Viewer) can connect an authorized client.

## Setup

Two things need to be in place before you can connect an app.

1. **A workspace Owner must authorize the client.** Every client is off by default. An Owner turns each one on separately, under **Settings > AI > Authorized apps**. Once a client is authorized, any member of the workspace with full access can connect it.
2. **You need full access to the workspace.** Members with Limited Viewer access can't connect apps to that workspace. An Owner or Admin can change your role under **Settings > Workspace > Members**.

### Supported clients

Francis supports the following AI clients. A workspace Owner authorizes each one separately before members can connect it.

- Claude
- Claude Code
- ChatGPT
- Codex
- Cursor
- GitHub

Using a client that isn't on the list? Email [support@francis.app](mailto:support@francis.app) and the Francis team will consider adding it.
